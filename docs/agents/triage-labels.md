# Triage Labels

| Canonical role    | Local Status value |
| ----------------- | ------------------ |
| `needs-triage`    | `needs-triage`     |
| `needs-info`      | `needs-info`       |
| `ready-for-agent` | `ready-for-agent`  |
| `ready-for-human` | `ready-for-human`  |
| `wontfix`         | `wontfix`          |

Use the matching value in a ticket's `Status:` line.
