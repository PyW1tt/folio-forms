# Domain Docs

This repo uses one domain context.

- Read root `CONTEXT.md` before exploring domain behavior. Use its terms in specs, tickets, code, and tests.
- Read relevant ADRs under root `docs/adr/` before changing an area they cover.
- Surface conflicts with an accepted ADR instead of silently overriding it.
- If a glossary or ADR does not exist, proceed; create one only when a term or decision is resolved.
