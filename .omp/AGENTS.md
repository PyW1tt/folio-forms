# Project instructions

## Code exploration

Use CodeGraph first for code flow, relationships, callers, callees, and change impact.

## Code changes

- Use the root `package.json` scripts to format and lint code before committing.
- Preserve input validation, error handling that prevents data loss, and accessible HTML with labelled controls and keyboard access.
- Use refs as props instead of `React.forwardRef`.

## Workflow references

- Issues and specs: read the [issue tracker](../docs/agents/issue-tracker.md) before publishing local Markdown.
- Ticket status changes: read the [triage labels](../docs/agents/triage-labels.md).
- Domain exploration or architecture changes: read the [domain docs](../docs/agents/domain.md) first.
